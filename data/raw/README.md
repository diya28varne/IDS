# Local recorded datasets

Place authorized network-flow CSV files here (for example a local CICIDS2017 or UNSW-NB15 extract).

- Files in this folder are ignored by Git except this README and `.gitkeep`.
- ThreatLens does not download datasets automatically.
- Do not commit large CSVs or data you are not licensed to redistribute.

Until a real dataset is present, tests use `tests/fixtures/synthetic_flows.csv`.
